# Prototype effect emblems

These are throwaway prototype assets generated with the built-in ImageGen tool in `logo-brand` mode. Each emblem was requested in its own generation call as one centered, abstract, 3–5-shape industrial glyph: opaque white geometry, no text, no conventional waveform/envelope/knob drawing, and a transparent background. The compressor received a second simplify/edit pass.

Metaphors used: opposing clamps (compressor), wedge through a notch (drive), faceted core (saturator), aligned stacked bands (OTT), orbiting crescents (chorus), interlocking rings (phaser), receding blocks (delay), descending pixels (crusher), three offset pegs (EQ), aperture blades (filter), nested arches (reverb), opposing petals (pan), interleaved combs (flanger), and a block between hard boundaries (limiter).

ImageGen's returned previews contained RGB transparency-preview pixels, so the selected generated artwork was mechanically thresholded, trimmed, centered, and exported as true-alpha 96×96 PNGs. These files are prototype-only and do not change the production icon policy.
