# Prototype effect emblems

`*-v2.png` is the colored set consumed by the compact mobile prototype. Each effect was generated separately with the built-in ImageGen tool. The shared prompt contract was: one bold synthesizer-FX silhouette that remains legible at 10–16 px, two effect-specific luminous colors, roughly 68% canvas occupancy, generous transparent padding, true alpha, and no text, tile, backplate, enclosing circle, white monochrome treatment, photorealism, or 3D button styling.

Metaphors used: echo pulses (delay), spectral curve and nodes (EQ), opposing pressure jaws (compressor), clipped waveform (drive), rounded harmonic waveform (saturator), three bands meeting a ceiling (OTT), doubled wave ribbons (chorus), interlocking phase lobes (phaser), wave-to-pixel steps (crusher), cutoff wedge (filter), expanding chamber arcs (reverb), stereo orbit (pan), interleaved comb sweeps (flanger), and a peak stopped by a ceiling (limiter).
