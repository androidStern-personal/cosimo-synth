Implemented product state
- The real Cmajor rack is in the main synth graph: Global Filter, Distortion, OTT, Chorus, Flanger, Phaser, Delay, and Reverb.
- `sharedEngine.rackModOut` is connected to `rack.rackModIn`; rack destinations are real modulation targets. Voice sources use Mean/Max reduction, while macro/global sources do not.
- The deployed React synth UI now has an ordered eight-module rack with enable/bypass, drag/drop reorder, mobile reorder buttons, selected-module detail editors, and compact collapsed controls.
- Distortion and Chorus reuse their established controls; OTT reuses the lab vocabulary. Phaser and Delay expose mutually correct Free/Sync controls.
- Rack identity/rendering is derived from `ui/shared/rack-parameter-descriptors.ts`; audio icons are vendored fontaudio SVGs with attribution in `CREDITS.md`.
- Browser state uses one strict schema: `rack.v1` = `{format, version, order, enabled}`. It restores once per DSP session, writes real rack events, and reads effective state back from Cmajor.
- Reordering previews optimistically in the UI and commits the DSP structure once on drop. The DSP transitions processed contribution through dry instead of repeatedly muting the instrument.
- Time-based effects use constant-sum mix law, reverb has useful early energy, and Phaser/Delay sync mappings are monotonic and consistent.
- The Web build still runs Cmajor `generate --target=webaudio-html` from `WavetableSynth.cmajorpatch`; it embeds the real generated WebAssembly and has no external compiler/runtime dependency.
