# Cosimo Buildlapse

This is the editable Remotion project for the Cosimo promotional buildlapse.

The `public/` directory is intentionally local and ignored. It is populated
with the rendered hero clip, final hero still, Blender render frames, and UI
timelapse frames before previewing or rendering the composition. Those media
files are generated inputs, not source-controlled project files.

Run `npm install`, then `npm run check`, `npm run studio`, or `npm run render`.
